# Aula 1 — INTRODUÇÃO AO GITHUB, CRIANDO REPOSITÓRIO E ENVIANDO ARQUIVOS

# 🎯 Objetivos da Aula

- Compreender o que é o GitHub.
- Criar uma conta no GitHub.
- Criar um repositório.
- Enviar arquivos para o repositório.
- Entender que todas as atividades da disciplina serão entregues pelo GitHub.

# 🧩 O que é o GitHub?

O **GitHub** é uma plataforma utilizada para armazenar projetos de programação.

Imagine que seja como um **Google Drive para códigos**, porém muito mais poderoso.

Nele podemos:

- armazenar projetos;
- compartilhar código;
- trabalhar em equipe;
- acompanhar alterações;
- testar automaticamente nossos programas.

Durante toda a disciplina, utilizaremos o GitHub para entregar exercícios e projetos.

# 🧱 O que é um repositório?

Um **repositório** é uma pasta do projeto dentro do GitHub.

Cada projeto normalmente possui seu próprio repositório.

Exemplo:

```
logica-programacao
```

Dentro dele ficarão todos os arquivos da disciplina.

# 📌 Criando um repositório

Após acessar o GitHub:

1. Clique em **New Repository**.
2. Escolha um nome.
3. Marque como Público.
4. Marque:

✅ Add README

1. Clique em **Create Repository**.

Pronto.

Você já possui seu primeiro projeto.

# 📂 O arquivo README

Todo projeto normalmente possui um arquivo chamado:

```
README.md
```

Ele serve para explicar o projeto.

Exemplo:

```markdown
# Lógica de Programação

Repositório utilizado para as atividades da disciplina.
```

# 📤 Enviando arquivos

Após criar um arquivo, podemos enviá-lo ao GitHub.

Basta:

- Add File
- Upload Files
- Escolher o arquivo
- Commit Changes

Esses passos serão repetidos durante todo o curso.

Quando todos os testes passarem, significa que o exercício foi concluído corretamente.
