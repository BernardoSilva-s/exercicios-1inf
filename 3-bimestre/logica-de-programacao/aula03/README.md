# 🧩 O que é JavaScript?

O **JavaScript (JS)** é uma linguagem de programação criada para adicionar comportamento às páginas da internet.

Inicialmente, ele era utilizado apenas nos navegadores, mas hoje pode ser usado para criar:

- Sites interativos;
- Sistemas web;
- Aplicativos para celular;
- APIs e servidores;
- Jogos;
- Inteligência Artificial;
- Automações.

É uma das linguagens mais utilizadas do mundo.

# 🌐 Onde encontramos JavaScript?

Alguns exemplos de aplicações desenvolvidas com JavaScript:

- YouTube
- Netflix
- Instagram
- Discord
- Spotify
- ChatGPT (parte da interface)

Sempre que um botão muda de cor, uma janela aparece ou uma página atualiza sem recarregar, existe uma grande chance de haver JavaScript funcionando.

# 📌 Como o JavaScript executa instruções

Um programa é composto por várias instruções.

Exemplo:

```jsx
console.log("Olá")
console.log("Bem-vindo")
console.log("JavaScript")
```

Cada linha é executada de cima para baixo.

A saída será:

```
Olá
Bem-vindo
JavaScript
```

# 💻 Executando JavaScript

Durante a disciplina utilizaremos:

```
node index.js
```

O Node.js será responsável por executar nossos programas.

# 🧩 O console

O comando mais utilizado nas primeiras aulas será:

```jsx
console.log("Mensagem")
```

Ele escreve informações na tela.

Exemplo:

```jsx
console.log("Estou aprendendo JavaScript")
```

Saída:

```
Estou aprendendo JavaScript
```
