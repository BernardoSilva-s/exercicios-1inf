# 🎯 Objetivos da Aula

- Conhecer a origem do JavaScript.

- Aprender o conceito de sintaxe.
- Escrever comandos respeitando a sintaxe do JavaScript.

# 🧩 Como surgiu o JavaScript?

Em 1995, a empresa Netscape queria tornar suas páginas mais interativas.

Para isso, o programador **Brendan Eich** criou uma nova linguagem em apenas alguns dias.

Essa linguagem recebeu o nome de **JavaScript**.

Com o passar dos anos, ela evoluiu e hoje é uma das linguagens mais utilizadas no mundo.

# 📜 O que é sintaxe?

Sintaxe é o conjunto de regras que define como um código deve ser escrito.

Assim como existe gramática na língua portuguesa, existe sintaxe nas linguagens de programação.

Exemplo correto:

```jsx
console.log("Olá")
```

Exemplo incorreto:

```jsx
console.log("Olá"
```

Falta o fechamento do parêntese, gerando um erro de sintaxe.

# 📌 Respeitando a sintaxe

Todo programa deve seguir regras como:

- abrir e fechar parênteses;
- abrir e fechar aspas;
- escrever corretamente os comandos;
- utilizar letras maiúsculas e minúsculas corretamente.

Por exemplo:

```jsx
console.log("Olá")
```

é diferente de:

```jsx
Console.log("Olá")
```

JavaScript diferencia letras maiúsculas de minúsculas.

# 🧩 Case Sensitive

JavaScript é uma linguagem **Case Sensitive**, ou seja, diferencia letras maiúsculas e minúsculas.

Exemplo:

```jsx
const nome = "Maria"
const Nome = "João"

console.log(nome)
console.log(Nome)
```

As duas variáveis são diferentes.
