# Aula 4 — O QUE É LINGUAGEM DE PROGRAMAÇÃO

# 🎯 Objetivos da Aula

- Compreender o conceito de linguagem de programação.
- Entender como computadores executam instruções.
- Conhecer exemplos de linguagens.
- Diferenciar linguagem humana de linguagem de programação.

# 🧩 O que é uma linguagem de programação?

Uma linguagem de programação é um conjunto de regras utilizado para escrever instruções que o computador consegue interpretar.

Assim como pessoas utilizam idiomas diferentes para conversar, computadores utilizam linguagens de programação para receber comandos.

# 💬 Linguagem humana × Linguagem de programação

Pessoa:

```
Faça um café.
```

Computador:

```jsx
ligarCafeteira()
adicionarAgua()
adicionarCafe()
prepararCafe()
```

O computador precisa receber todas as instruções de forma organizada.

# 🤖 O computador não pensa

O computador apenas executa exatamente aquilo que foi programado.

Se houver erro nas instruções, o programa também produzirá resultados incorretos.

Por isso a lógica é tão importante.

# 🌎 Algumas linguagens famosas

| Linguagem | Utilização |
| --- | --- |
| JavaScript | Sites e sistemas web |
| Python | IA, automação e ciência de dados |
| Java | Sistemas empresariais |
| C# | Jogos e aplicações |
| PHP | Sistemas web |
| C++ | Jogos e sistemas |

Todas possuem o mesmo objetivo: resolver problemas.

# 📌 O papel do programador

O programador recebe um problema e escreve uma sequência de instruções para resolvê-lo.

Exemplo:

Problema:

```
Mostrar uma mensagem ao usuário.
```

Solução:

```jsx
console.log("Bem-vindo!")
```
